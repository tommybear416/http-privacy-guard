# Adoption evidence

As of 2026-10-07, no independent downstream adopter has been verified. No npm package, monthly registry download count, Debian/Fedora/Homebrew core inclusion or ecosyste.ms critical flag has been established. The example and tests in this repository are demonstrations, not downstream adopters.

The component is intended to be an upstream dependency for applications that handle private documents. A separate private application remains downstream. Intended integration, a candidate patch, an owner-controlled demo or documentation describing the relationship does not prove production adoption or broad ecosystem dependence.

Record an adopter only with its consent and evidence such as a public dependency manifest pinned to a release/source commit and a real integration that executes the control. Do not publish a private consumer's name, repository, architecture or usage data without authorization.

GitHub's [dependency-graph guidance](https://docs.github.com/en/code-security/how-tos/secure-your-supply-chain/secure-your-dependencies/explore-dependencies) explains that the dependents view shows public repositories. A private consumer cannot provide a public dependent-repository count there. A source install may also not appear as a recognized registry dependency. Do not equate stars, forks, page views, CI runs or this repository's own tests with the form's adoption metrics.

## Application fields

After the public repository exists, its canonical URL can establish the project and `MAINTAINERS.md` can show the security-maintainer role. A separate identity-to-handle link is still needed if requested by the provider. The adoption option and figure link remain unsupported until the relevant evidence exists.

The [Anthropic Cyber Verification Program](https://www.anthropic.com/news/cyber-verification-program) also describes Defense Access for organizations securing systems they own or maintain. The applicant should choose a route that reflects their actual work and evidence. This repository does not guarantee eligibility or approval under an open-source adoption category.
