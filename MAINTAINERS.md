Maintainer responsibilities include reviewing security reports, reproducing issues using synthetic cases, reviewing fixes and documenting supported releases. Maintenance is performed when instructed by the project owner. There is no staffed response SLA, continuous human monitoring or automatic agent repair service. Dependency update proposals and CI do not imply that a proposal has been reviewed or deployed.
